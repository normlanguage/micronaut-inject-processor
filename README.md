# Micronaut Inject Java

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration is in `micronaut/inject/processor`. It pins Micronaut Inject Java 5.1.13 and defines its package coordinates in [module.norm](micronaut/inject/processor/module.norm). This module provides the official Micronaut JSR 269 processor.
